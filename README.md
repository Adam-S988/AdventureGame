# Text-Based Adventure Game

Explore a richly crafted world filled with towns, forests, mountains, and hidden secrets! Interact with NPCs, find items, and uncover the story behind this mysterious land.

---

## 📖 Overview

This is a text-based adventure game developed in Java. The player can:
- Move between different locations (e.g., Town, Forest, Graveyard).
- Interact with NPCs (Non-Playable Characters).
- Find and collect items.
- Experience an immersive narrative-driven exploration.

---

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) version 11 or later.
- An IDE (e.g., IntelliJ, Eclipse) or a text editor and terminal.

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/YourUsername/AdventureGame.git
    cd AdventureGame
    ```
2. Open the project in your preferred IDE.
3. Build the project to ensure all dependencies are correctly configured.

---

## 🎮 How to Play

- **Start the game** by running the main class:
    ```bash
    java com.keyin.GameEngine
    ```
- **Controls**:
    - `go [direction]`: Move in a specified direction (e.g., go north, go west).
    - `look`: Inspect your surroundings and see nearby items.
    - `talk to [NPC name]`: Start a conversation with an NPC.
    - `take [item]`: Pick up an item.
    - `quit`: Exit the game.

## 🌍 World and Locations

The game world includes:
- **Town** - A bustling marketplace.
- **Forest** - Dark and full of towering trees.
- **Mountain** - Rocky paths with hidden dangers.
- **Graveyard** - Overgrown and eerie.
- **River** - A fast-flowing stream with a bridge.

---

## 👥 Interactions

### NPCs
You can meet various NPCs throughout the world, each with unique dialogues and lore. Use `talk to [NPC name]` to interact with them.

### Items
Items are scattered throughout the land. Use `look` to find them and `take [item]` to collect them. Items might be useful for quests or solving puzzles.
